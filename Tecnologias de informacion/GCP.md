|**Categoría**|**Servicio**|**Modelo**|**¿Qué soluciona? (Súper Breve)**|
|---|---|---|---|
|**Cómputo**|Compute Engine|**IaaS**|Máquinas virtuales personalizables de alto rendimiento.|
||Cloud Functions/Run|**PaaS**|Ejecución Serverless de funciones y contenedores.|
||GKE (Kubernetes)|**PaaS**|El estándar líder en orquestación de Kubernetes gestionado.|
|**Almacenamiento**|Cloud Storage|**IaaS**|Almacenamiento unificado de objetos (frecuente a frío).|
||Persistent Disk|**IaaS**|Almacenamiento en bloque fiable para VMs.|
||Filestore|**IaaS**|Almacenamiento de archivos NFS de alto rendimiento.|
|**Base de datos**|Cloud SQL|**PaaS**|Gestión de MySQL, PostgreSQL y SQL Server.|
||Cloud Spanner|**PaaS**|SQL relacional con escalabilidad horizontal global infinita.|
||Firestore|**PaaS**|NoSQL con sincronización en tiempo real para apps web/móvil.|
|**Redes**|VPC|**IaaS**|Red privada virtual de alcance global nativo.|
||Cloud CDN|**PaaS**|Aceleración de contenido web usando los nodos de Google.|
||Cloud Load Balancer|**IaaS**|Distribución masiva de tráfico a nivel mundial sin precalentamiento.|
|**Seguridad**|Cloud IAM|**SaaS**|Administración centralizada de permisos y roles.|
||Secret Manager|**PaaS**|Almacenamiento cifrado y versionado de credenciales.|
||Cloud Armor|**PaaS**|Defensa de grado Google contra ataques DDoS y WAF.|
|**Analítica**|BigQuery|**SaaS**|Data warehouse serverless para analizar petabytes con SQL.|
||Dataproc|**PaaS**|Clústeres gestionados para Hadoop y Spark.|
||Dataflow|**PaaS**|Procesamiento unificado de datos (Stream y Batch).|
|**IA y ML**|Vertex AI|**PaaS**|Plataforma unificada para entrenar y desplegar modelos (MLOps).|
||Vision AI|**SaaS**|API lista para usar para reconocimiento en imágenes (OCR).|
||Dialogflow|**SaaS**|Motor de lenguaje natural para crear chatbots avanzados.|
|**Gestión**|Terraform en GCP|**PaaS**|Aprovisionamiento de infraestructura como código.|
||Cloud Ops Suite|**PaaS**|Diagnóstico, métricas y registro (antes Stackdriver).|
||Cloud Build|**PaaS**|Tuberías rápidas y automatizadas de integración continua (CI/CD).|
