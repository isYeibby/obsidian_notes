| **Categoría**      | **Servicio**       | **Modelo** | **¿Qué soluciona? (Súper Breve)**                                                                      |
| ------------------ | ------------------ | ---------- | ------------------------------------------------------------------------------------------------------ |
| **Cómputo**        | Amazon EC2         | **IaaS**   | Servidores virtuales bajo demanda.                                                                     |
|                    | AWS Lambda         | **PaaS**   | Ejecución de código basada en eventos (Serverless).                                                    |
|                    | Amazon ECS / EKS   | **PaaS**   | Orquestación de contenedores (Docker/Kubernetes).                                                      |
| **Almacenamiento** | Amazon S3          | **IaaS**   | Almacenamiento masivo de objetos y archivos.                                                           |
|                    | Amazon EBS         | **IaaS**   | Discos duros virtuales para instancias EC2.                                                            |
|                    | Amazon EFS         | **IaaS**   | Sistema de archivos en red (NFS) compartido.                                                           |
| **Base de datos**  | Amazon RDS         | **PaaS**   | Bases de datos relacionales gestionadas (SQL).                                                         |
|                    | Amazon DynamoDB    | **PaaS**   | Base de datos NoSQL de clave-valor ultrarrápida.                                                       |
|                    | Amazon ElastiCache | **PaaS**   | Caché en memoria (Redis/Memcached) para acelerar lecturas.                                             |
| **Redes**          | Amazon VPC         | **IaaS**   | Red privada virtual y aislamiento de recursos.                                                         |
|                    | Amazon CloudFront  | **PaaS**   | Red global de entrega de contenido (CDN).                                                              |
|                    | Amazon Route 53    | **PaaS**   | Gestión de DNS y enrutamiento de tráfico.                                                              |
| **Seguridad**      | AWS IAM            | **SaaS**   | Control de identidades y permisos de acceso.                                                           |
|                    | AWS KMS            | **PaaS**   | Creación y administración de claves de cifrado.                                                        |
|                    | AWS WAF            | **PaaS**   | Firewall para proteger aplicaciones de ataques web.                                                    |
| **Analítica**      | Amazon Athena      | **SaaS**   | Consultas SQL directas sobre archivos en S3.                                                           |
|                    | Amazon Redshift    | **PaaS**   | Data warehouse masivo para analítica empresarial.                                                      |
|                    | Amazon Kinesis     | **PaaS**   | Procesamiento de flujos de datos en tiempo real.                                                       |
| **IA y ML**        | Amazon SageMaker   | **PaaS**   | Entorno para construir y entrenar modelos de IA.                                                       |
|                    | Amazon Rekognition | **SaaS**   | API lista para usar de análisis visual e imágenes.                                                     |
|                    | Amazon Bedrock     | **PaaS**   | Acceso unificado a modelos de IA Generativa.                                                           |
| **Gestión**        | CloudFormation     | **PaaS**   | Permite modelar y aprovisionar toda la infraestructura en la nube mediante archivos de texto o código. |
|                    | Amazon CloudWatch  | **PaaS**   | Monitoreo, logs y alertas del sistema.                                                                 |
|                    | AWS CodePipeline   | **PaaS**   | Automatización de integración y entrega (CI/CD).                                                       |
